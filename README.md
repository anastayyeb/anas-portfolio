# Anas Tayyeb — Portfolio Website

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript. No build tools or framework required.

## Preview locally

1. Extract the ZIP file.
2. Open `index.html` in a browser.

For local development, you can also run a simple server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing

- In `index.html`, replace `YOUR_EMAIL@example.com` in the contact button with the email address you want visitors to use.
- Add a real profile photo if desired; the current hero uses a designed initials illustration.
- Review the education and project descriptions and adjust any wording or dates you want represented differently.
- Add verified project screenshots, certificates, CV and social profile links when ready.

## Publish

This is a static website and can be hosted on GitHub Pages, Netlify, Cloudflare Pages or any standard web host. Upload the contents of this folder (keeping `index.html`, `styles.css` and `script.js` together).
